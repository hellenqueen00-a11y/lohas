# LOHAS 모바일 웹 브로셔

실제 제공 사진과 영상으로 만든 한국 여행사 팸투어용 첫 시안입니다.

별도의 빌드가 필요 없는 정적 웹사이트입니다. GitHub에 이 폴더 내용을 올린 뒤 Vercel에서 프레임워크를 Other로 선택해 배포할 수 있습니다. index.html을 직접 열어 검토하는 것도 가능합니다.

## 공개 전 확인

- 담당자 연락처 및 정확한 지도 위치 추가
- 바지선 완공 및 운영 시작일 업데이트 (현재 제작 중, 약 50명, 전기시설 없음)
- 시설 이용 및 차량 이동 조건 확인
- 촬영 자료의 현재 시설 상태, 인물 및 사용 권한 확인
- 향후 공항 라운지 구상은 현재 운영 서비스와 구분 유지

객실 요금은 공개하지 않았습니다. 바지선 계획 이미지를 포함했으며, 태양광·전기시설 표현이 실제 사양과 다름을 이미지 아래에 명시했습니다. 현재 제공된 영상은 소리를 제외한 웹용 편집본으로 사용합니다.
